# مدرسه‌یار دانش‌آموز — Android 1.12.0

## مشکل ریشه‌ای
پنل هاست 72.89.15 خودش Bridge پایدار همگام‌سازی و نمایش «آخرین به‌روزرسانی موفق» را داشت، اما APK بعد از بارگذاری صفحه، داشبورد را با `girl-dashboard.js` محلی بازطراحی می‌کرد. CSS اندروید محتوای اصلی داشبورد هاست را مخفی می‌کرد و کد APK هنوز برای Sync وارد صفحه «بیشتر» می‌شد و `#manualSyncBtn` را صدا می‌زد. در نتیجه اصلاح هاست در UI اندروید دیده نمی‌شد و در بعضی زمان‌بندی‌ها خطای آماده نبودن پنل رخ می‌داد.

## اصلاحات
- اتصال مستقیم به `MadreseyarStudentSync.syncNow()` و `getStatus()` در هاست 72.89.15.
- fallback سازگار برای نسخه‌های قدیمی‌تر پنل باقی مانده است.
- حذف gate سخت `navigator.onLine` از داشبورد اندروید.
- حذف gate سخت `hasInternet()` از `MainActivity.updateNow()`.
- نمایش تاریخ و ساعت شمسی آخرین همگام‌سازی موفق روی صفحه اول APK.
- عدم تغییر زمان موفق در Sync ناقص/ناموفق.
- `versionCode=12`, `versionName=1.12.0`.
